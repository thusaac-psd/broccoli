# 输出比较

每道题目都有一种比较方式（checker format），它决定如何把选手程序在每个测试
点上的输出与标准输出进行比较。在题目表单的比较方式一项中选择。

## 默认按行比较

新题目默认使用 `lines`，创建题目时未指定比较方式的，服务器同样使用 `lines`。
它逐行比较输出，忽略每行末尾的空白字符、Windows 换行符以及输出末尾的空行。
因此，标准输出填写为 `3` 时，与输出 `3` 后再输出换行的程序相匹配，`print(3)`
和 `cout << 3 << endl` 都是这样输出的。

## 比较方式

| 比较方式 | 判为通过的条件 |
| --- | --- |
| `lines` | 去掉行末空白和末尾空行后，每一行都相同 |
| `exact` | 输出与标准输出的字节完全相同，包括换行符 |
| `tokens` | 以相同顺序出现相同的单词，与空白和换行的分布无关 |
| `tokens-case-insensitive` | 与 `tokens` 相同，但不区分大小写 |
| `tokens-float` | 与 `tokens` 相同，但数字在容差范围内比较 |
| `testlib` | 题目自带的 testlib 比较器判为通过 |
| `none` | 程序正常运行结束即通过，不做任何比较 |

只有在确实需要逐字节比较时才使用 `exact`，例如考查输出格式的题目。使用
`exact` 时，如果标准输出漏掉了最后的换行符，所有正确的程序都会被判为答案错误。

## 数字的容差

`tokens-float` 在一个数字与标准答案的差不超过两个界限中较大的那个时判为通过。
绝对容差是一个固定的量，默认为 `1e-9`。相对容差是两个数中较大者的一个比例，
默认为 `1e-6`。不是数字的单词仍需完全相同。

要为某一道题目修改容差，打开该题目的插件设置，填写标准比较器插件（standard
checkers）的 `checker` 设置。保存时，小于零的值或不是数字的值会被拒绝。
