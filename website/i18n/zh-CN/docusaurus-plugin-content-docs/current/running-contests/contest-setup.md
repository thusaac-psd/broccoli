# 创建比赛

在管理区的比赛页面创建比赛。四个时间决定谁能看到比赛以及比赛何时接受提交，
比赛类型决定比赛如何评测和排名。

## 激活决定谁能看到比赛

| 时间 | 作用 |
| --- | --- |
| 激活时间 | 从此时起选手可以看到比赛 |
| 开始时间 | 开始接受提交 |
| 结束时间 | 停止接受提交 |
| 停用时间 | 从此时起选手不再看到比赛 |

这些时间必须按上述顺序排列。激活时间和停用时间可以不填，但两者留空时的效果不同。

没有激活时间的比赛是草稿。无论开始和结束时间如何设置，只有比赛管理者能看到它，
因此从未激活的比赛永远不会对选手可见。管理区的比赛列表把它标记为草稿（未激活）。
准备题目和设置时可以保持草稿状态，等到选手应当看到比赛时，再设置激活时间，或者在
比赛表单中点击立即激活。

激活时间在未来的比赛在此之前显示为待激活。没有停用时间的比赛在结束后仍然可见。

## 比赛类型在第一次提交后固定

比赛类型选择评测和排名比赛的插件，例如 ICPC 或 IOI。在比赛收到第一次提交之前
可以修改它。此后比赛表单将其显示为只读，服务器也会拒绝修改，因为一场比赛的所有
提交都按同一套规则评测和排名。
