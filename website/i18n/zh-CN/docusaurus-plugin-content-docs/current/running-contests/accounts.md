# 账号与注册

选手需要先有账号才能登录。默认由管理员创建账号；只有比赛需要时才开放自行注册。

## 创建账号

拥有用户管理权限的管理员在**用户**页面创建账号，可以逐个创建，也可以一次批量导入最多 100 个。批量导入要么全部成功，要么全部不创建：只要有一个用户名已被占用，就不会创建任何账号，错误信息会列出所有已被占用的用户名。

用户名不区分大小写。`Alice` 和 `alice` 是同一个账号，因此无法再创建第二个，两种写法都可以登录。账号显示时保留创建时的大小写。

## 自行注册

全新安装时自行注册是关闭的。关闭期间，注册页面会提示访问者向组织者索取账号，`POST /api/v1/auth/register` 返回 `403 REGISTRATION_CLOSED`。

拥有用户管理权限的管理员可以在**用户**页面用**开放注册**开关打开或关闭注册。修改立即对所有服务器生效，无需重启，因此可以在比赛进行中关闭注册。对应的接口是 `PUT /api/v1/admin/settings/registration`，请求体为 `{"open": true}` 或 `{"open": false}`；`GET /api/v1/auth/registration` 返回当前状态。

## 登录频率限制

每个客户端地址每分钟最多尝试登录 10 次（在所有服务器之间合计），注册或申请 CLI 设备码每分钟最多 30 次。超过限制的客户端会收到带 `Retry-After` 头的 `429 RATE_LIMITED`；提前重试不会延长等待时间。如果所有选手经过同一个 NAT 而在服务器看来是同一个地址，请用 `server.rate_limit_auth = false` 关闭登录限制。
