# 插件设置

插件可以提供由管理区填写的设置项。根据设置项的不同，同一个值最多可以在四
个级别中分别配置，从覆盖整个服务器的值，一直到某场比赛中某一道题目的值。

## 四个级别

| 级别 | 覆盖范围 | 谁可以设置 |
| --- | --- | --- |
| 全局 | 服务器上的每一场比赛 | 插件管理 |
| 题目 | 一道题目，无论它出现在哪里 | 题目编辑 |
| 比赛 | 一场比赛 | 比赛管理 |
| 比赛题目 | 一场比赛中的一道题目 | 比赛管理 |

## 哪个级别生效

比赛题目的值优先于比赛的值，比赛的值优先于题目的值。这三个级别会自动组
合，其中最精细的那一个级别生效。全局则不一样，定义该设置项的插件会自行
读取全局的值，全局的值只在插件自己选择使用它的地方生效，并不是在其他三
个级别都没有设置时自动生效的兜底值。

以冷却时间插件的提交冷却时间为例。某场比赛把它设置为六十秒，该比赛中的一
道比赛题目又把它设置为三十秒。这场比赛中的每道题目提交间隔都是六十秒，唯
独那道有自己单独设置的比赛题目，提交间隔是三十秒。

关闭一个设置项的道理类似，但仅限于管理表单提供开关的级别，也就是比赛和
题目这两个级别。你所设置过的级别中最精细的那一个，决定这个功能是开还是
关，无论范围更广的级别怎么设置。在比赛级别关闭某个设置项，即使题目级别
保持开启，整场比赛的这个设置项依然是关闭的。

## 在哪里设置

在管理区打开插件页面，选择某个插件，再打开它的设置。即使还没有保存过任何
值，表单也会显示这个插件的设置项，因为表单的结构来自插件本身，而不是来自
已保存的记录。比赛和比赛题目的值要在比赛自己的设置里配置，而不是在插件页
面配置。

:::note[默认值不会被保存]

你没有设置过的级别会保持默认值，不会覆盖范围更广的级别。只有你保存过的值
才算是已设置。

:::

## 服务器拒绝的值

每个设置项都有类型，通常还有取值范围，服务器会在保存时检查每一个值。类型错误、超出范围或不在
可选项之中的值不会被保存，表单会标出服务器拒绝的字段。因此，已保存的值总是与表单显示的含义一致。
